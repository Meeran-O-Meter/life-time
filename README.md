LifeTime is essentially just a stopwatch, that counts your entire lifetime in terms of hours, minutes and seconds so you can compare what you've done in your lifetime to the Chinese kid next door <br>


It was initially just a fun project inspired with a newly found addiction about time-based designs,but if I'm being honest I learnt a whole lot more than I expected during this project.

# Why I started this project
I did start it because I thought it'd be a quick 2 hour project but it turned out to be a whole lot more complicated with the amount of time I was absent from coding this year and overall JavaScript. 
I also wanted to implement my design from sunpray into more micro projects, and I saw this to be a great opportunity to do so. 

# Highlights of this project
One of the main problems I faced during this project was the logic.
